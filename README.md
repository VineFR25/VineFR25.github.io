# Vinicius Rocha — Finance Portfolio

Static portfolio website built with HTML, CSS and JavaScript.

## Deploy with GitHub Pages

### Recommended: personal GitHub Pages site
1. Create a **public** repository named exactly:
   `vinefr25.github.io`
2. Upload everything inside this folder to the root of the repository.
3. Commit the files to the `main` branch.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. Your website will be available at:
   `https://vinefr25.github.io`

## Files
